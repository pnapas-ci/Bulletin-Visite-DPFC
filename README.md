# Bulletin de visite DPFC provisoire

Outil numérique de rédaction des bulletins de visite de classe (DPFC – PNAPAS), utilisable en ligne et hors ligne.

- **Application** : `index.html` (page d'accueil du site)
- **Version d'essai** : `essai.html`, utilisable jusqu'au dimanche 23 novembre 2026 inclus. Chaque appareil reçoit un identifiant (ESSAI-XXXX-XXXX), affiché en haut de l'écran. Après l'essai, l'outil se débloque sur l'appareil avec le code d'activation que la DPFC fabrique à partir de cet identifiant ; le code vaut pour l'année scolaire 2026-2027, jusqu'au 31 août 2027.
- **Téléchargements** (dossier `telechargements/`) : fichier hors ligne, version d'essai et paquet du site.
- **Serveur de la plateforme** : `Code_serveur_Google_Apps_Script.gs` (voir `LISEZ-MOI.txt`).

Utilisation en ligne et hors ligne : ouvrir le lien une première fois avec une connexion ; la page est alors enregistrée et s'ouvre ensuite sans connexion. Sur le téléphone : ouvrir le lien dans Chrome, puis menu ⋮ → « Ajouter à l'écran d'accueil » (l'icône de la version d'essai ouvre la version d'essai).
